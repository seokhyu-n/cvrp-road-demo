# SPEC — cvrp-road-demo

## 목표
- 지도에서 창고·고객·물류량을 입력하면 AI가 회차를 나눈 배송 경로를 제안하고, 실제 도로 거리/시간과 함께 보여 주는 웹 데모.
- 포트폴리오로서 "AI 모델이 실제로 얼마나 잘하는지"를 재현 가능한 숫자로 설명할 수 있어야 한다.

## 범위
- 포함: 모델 추론 파이프라인(정규화·샘플링·후처리), FastAPI 서버, Leaflet UI, 평가 스크립트와 Run 기록, Render 배포.
- 제외(현재): 실시간 교통, 시간창(time window) 제약, 다중 창고.

## 완료 기준
- 데모 결과가 NN baseline보다 평균적으로 짧다 (현재 n20 +13.2%, n50 +14.3%).
- OR-Tools 참조해 대비 gap을 평가셋(n20, n50)에서 기록하고 README에 제시한다.
- `python -m pytest -q` 전부 통과.
- 평가 결과는 `results/runs.csv`에 Run 단위로 남고, README 숫자는 특정 Run을 가리킨다.
- 공개 데모 `/solve`는 요청 크기 상한으로 보호된다.
